GitHub 릴리스 v1.2.7의 Windows x64 ZIP입니다. 체크섬은 파일 안전성 인증이 아닙니다.

투명하게 알려드릴게요

Windows에서 경고가 보일 수 있습니다.

앱은 코드 서명되지 않았고, 독립 보안 감사도 아직 받지 않았습니다. Windows SmartScreen이 실행을 막거나 확인을 요청할 수 있습니다.

체크섬은 안전 인증서가 아닙니다. SHA-256은 파일이 공개된 파일과 같은지 비교하는 방법일 뿐, 코드가 안전하다는 보장은 아닙니다.

설치 후에는 이렇게 됩니다.

앱이 무엇을 하는지 미리 확인할 수 있습니다.

01

ZIP을 받고 압축을 풀어요

압축을 푼 폴더에서 josimi.exe를 실행합니다. monerod와 필요한 파일은 Windows ZIP에 포함되어 있어 따로 찾을 필요가 없습니다.

02

새 지갑·기존 지갑·복구 중 고릅니다

새 지갑을 만들거나, 기존 .keys 파일을 열거나, 복구 문구로 되살릴 수 있습니다. 비밀번호와 복구 문구는 이 앱에서만 입력하세요.

03

로컬 노드가 자동으로 동기화합니다

새 지갑은 노드 연결을 기다리지 않고 먼저 만들 수 있어요. 로컬 노드와 지갑 동기화는 뒤에서 자동으로 이어집니다. 첫 동기화 전에는 잔액과 거래 내역이 늦게 표시될 수 있습니다.

개인정보를 설명할 때 좋은 말만 남기면 안 되니까요. 연결 방식마다 실제 차이를 적었습니다.

01

지갑 파일은 이 PC에

josimi는 비수탁 지갑입니다. 지갑 파일과 복구 문구를 외부 계정으로 보내지 않습니다. 다만 컴퓨터를 잃거나 파일이 손상되면 복구 문구 백업이 필요합니다.

02

로컬 노드도 네트워크에 연결됩니다

내 PC에서 monerod를 실행해도 Monero P2P 피어와 통신하므로 IP 주소가 네트워크에 노출될 수 있습니다. 로컬 RPC는 127.0.0.1에 묶여 있습니다. 기본 P2P 포트와 방화벽 설명은 앱의 노드 세부 정보에서 확인하세요.

03

공개 노드는 더 쉬울 수 있지만

공개 노드 운영자는 접속 IP와 요청 메타데이터를 볼 수 있고, RPC 요청으로 잔액이나 활동을 추론할 수 있습니다. 신뢰하는 노드만 선택하세요. 공개 노드는 앱 설정에서 직접 바꿀 수 있습니다.

04

아직 독립 감사를 받지 않았습니다

오픈소스라고 해서 자동으로 안전한 것은 아닙니다. 현재 Windows 빌드는 서명되지 않았고, 독립 보안 감사도 없습니다. 사용 전에 이 사실을 알고 결정해 주세요.

자주 묻는 질문

처음 사용할 때 궁금해지는 내용을 모았습니다.

노드가 준비되기 전에 지갑을 만들 수 있나요?

네. 새 지갑은 노드 연결을 기다리지 않고 먼저 만들 수 있어요. 노드가 준비되면 지갑 동기화가 자동으로 이어집니다. 복구하거나 기존 지갑을 여는 경우에는 선택한 노드 연결이 필요합니다.

첫 동기화가 오래 걸리는 게 정상인가요?

그럴 수 있습니다. Monero 블록체인을 처음 확인하므로 수 시간 또는 며칠이 걸릴 수 있고, 저장 공간과 네트워크 사용량도 큽니다. 동기화가 끝날 때까지 잔액이나 거래 목록이 바뀔 수 있습니다.

공개 노드로 바꿀 수 있나요?

네. 지갑 생성·복구 화면의 연결 설정에서 바꿀 수 있습니다. 대신 공개 노드 운영자가 IP와 연결 메타데이터를 볼 수 있으며, RPC 요청으로 지갑 잔액이나 활동을 추론할 수 있습니다.

체크섬을 확인하면 앱이 안전하다는 뜻인가요?

아닙니다. SHA-256 비교는 받은 파일이 게시된 파일과 같은지 확인할 뿐, 소프트웨어의 안전성이나 무결한 개발 과정을 보증하지 않습니다. 현재 앱은 독립 감사를 받지 않았고 Windows 코드 서명도 없습니다.

복구 문구를 어디에 저장해야 하나요?

복구 문구는 누구에게도 보내지 말고, 오프라인으로 안전하게 보관하세요. josimi에서는 현재 지갑 비밀번호를 다시 확인한 뒤에만 화면에 표시됩니다. 화면을 캡처하거나 클라우드 메모에 저장하는 일은 피하세요.

다운로드 링크가 열리지 않으면 어떻게 하나요?

GitHub API에서 버전을 가져오지 못하더라도 릴리스 페이지를 직접 열 수 있습니다. 파일을 받을 때 버전과 Windows x64 ZIP인지 확인하세요.
