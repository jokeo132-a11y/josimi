# Changelog

## v0.1.0 — 2026-10-11

- Windows x64 portable Electron wallet MVP
- Non-custodial local wallet creation and seed restore
- Mainnet default network
- Address copy and QR display
- Balance and transaction history
- Send flow with confirmation review
- Service fee: 0.25%, capped at 0.05 XMR
- Service fee destination validated as Monero mainnet address
- 15-minute inactivity lock
- Local wallet backup

> This release has not received an independent security audit. Use a small amount for testing only.
